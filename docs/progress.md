# Implementation and acceptance evidence — PRD 3.0

Updated 15 October 2026. The active specification requires Flutter for iOS and Android and Next.js for the operations dashboard. The starting repository contained only the PRD. The source, database, dashboard, mobile applications, and native integrations are now implemented. **P0 is not fully accepted:** physical iOS/Android airplane-mode, interruption, accuracy, and endurance gates remain outstanding.

## Delivered implementation

- Public landing page at `/`, workspace login at `/login`, and protected dashboard, template editor, engineer/type management, devices, and submission routes. The landing page has responsive layouts and a keyboard-accessible workflow explorer. The overview refreshes quietly every 15 seconds while visible and on focus. No public deployment was made.
- PostgreSQL migrations, idempotent synthetic seed, guarded development reset, shared Zod contracts, canonical JSON fixtures, and generated OpenAPI 3.1 documentation. Server services enforce role/ownership, revision checks, immutable published schemas, signed leases, frozen-byte hashes, stable receipts, and transactional cancellation fencing.
- Flutter feature modules with Riverpod/go_router, schema-rendered forms, local drafts, review with provenance, durable frozen outbox, receipts/retries, settings, secure local unlock, lease validation, SQLCipher storage, and isolated account key/database namespaces.
- Actual pinned Whistle/Needle C API integration through the local `field_voice` FFI package, and local Kokoro synthesis through sherpa-onnx. A persistent worker owns native model state. Asset downloads are authenticated, resumable, hash checked, and activated after complete verification and a local smoke test. No cloud speech/model fallback is present.
- Procedural three-dimensional fibre loop, spring press feedback, reduced-motion handling, and recording/playback indicators driven by real audio data. Four engineer types/templates are seeded; the app uses assigned identity rather than a role switch.

## Runtime measurements and limitations

Flutter 3.44.8 / Dart 3.12.2; host macOS 27.2 (26B5091g), Xcode 27.0 (27A266a). **No physical device was connected or tested.** The proposed iPhone 13/iOS 18 and ARM64 Android 12/6 GB baselines remain unverified.

Latest actual Mac smoke: load **5,530 ms**, extraction **5,234 ms**, cold synthesis **18,145 ms**, ASR **298 ms**, peak RSS **422,281,216 bytes**. This run overlapped Android compilation and resource pressure. These are single host measurements, exceed the proposed interaction targets, and are not phone p95 or full-shift results. Per-field model calls increase latency as the form grows. Optimization and isolated cold/warm measurements are still required.

The first nested optional tool schema failed with suppressed calls/confidence zero. The implemented adapter now uses one flat field-specific tool at a time with the same Needle model, explicit unit validation and narrow correction normalization. Actual host evidence returned 12 m and `not_tested`, leaving uncertain fields unresolved. The native API cannot unload its process-global weights; changing active model weights requires an app restart. Cancellation invalidates/discards work rather than interrupting the native call mid-operation.

Weights/assets: 362 files, 210,201,890 bytes. Exact source revisions, binary/model hashes and notices are in `fixtures/voice/model-sources.lock.json`, `fixtures/voice/asset-manifest.json`, and `runtime-manifest.md`. The full package includes eSpeak GPL-3.0 material; distribution obligations must be handled before publication.

Remaining work: physical gates in the matrix; 100 held-out utterances with measured numerator/denominator and adversarial outcomes; 20 complete reports and a 30-minute session per platform; phone latency/RAM/battery/thermal measurements; platform signing/distribution; operational retention scheduling. The proposed seven-day local/30-day server retention policy is documented but **not automatically enforced**. Pending reports are never automatically purged. Only the guarded explicit development reset deletes the synthetic dataset.

No credentials or assets are missing for local testing. There are no inference doubles in the demo application. Automated tests may use dependency fixtures; synthetic product-preview content on the landing page is explicitly labeled illustrative. Real microphone capture, physical security and airplane-mode acceptance must not be inferred from source, host results, or simulator status.
